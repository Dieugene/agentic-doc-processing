## Справка по задачам

### Итерация 1: Препроцессинг

**001 — Базовая настройка проекта и инфраструктуры**
- Инициализация структуры проекта
- Настройка TypeScript/Python окружения
- Базовое логирование
- Тестовый фреймворк

**002 — Реализация Координатора (базовый)**
- API для приёма архивов
- Оркестрация обработки
- Интеграция с Препроцессором

**003 — Реализация Распаковщика**
- Распаковка ZIP-архивов
- Обработка ошибок распаковки

**004 — Реализация Конвертера (с моком)**
- Mock-конвертер DOCX → PDF
- Определение поддерживаемых форматов

**005 — Реализация Группировщика (с моком)**
- Mock-логика группировки файлов
- Определение типов документов

**006 — Реализация Документ-юнит (пустой)**
- Контейнер для PDF-файлов
- Метаданные документа

**007 — Реализация базового Хранилища**
- JSON file storage
- Реестр документов

**008 — Реализация Препроцессора**
- Оркестрация модулей препроцессинга
- Обработка ошибок

**009 — Интеграционные тесты: ZIP → Документ-юниты**
- E2E тест препроцессинга
- Проверка реестра документов

**010 — Логирование и наблюдаемость (Итерация 1)**
- Структурированные логи
- Метрики обработки

### Итерация 3: Тематическая обработка

**018 — Реализация Топик-провайдера (опционально)**

**019 — Реализация Тематического анализатора**
- Создание топик-агентов
- Оркестрация разбора тем
- Построение навигационной матрицы

**020 — Реализация Топик-агента**
- Разбор одной темы
- Создание блок-агентов
- Агрегация результатов

**021 — Реализация Блок-агента**
- Извлечение данных из блока
- Query через VLM/LLM

**022 — Расширение Хранилища для тем и матрицы**
- Сохранение NavigationMatrix
- Сохранение Extract

**023 — Расширение Навигационного слоя (полный)**
- API для навигационной матрицы
- Поиск блоков по теме
- Получение выписок

**024 — API для инициирования разбора тем**
- POST /api/documents/{doc_id}/topics
- Поддержка TopicProvider

**025 — Интеграционные тесты: DocumentStructure → NavigationMatrix**
- E2E тест тематического разбора
- Проверка матрицы и выписок

**026 — Логирование и наблюдаемость (Итерация 3)**
